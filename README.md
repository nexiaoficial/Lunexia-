# Lunexia 2026

O aplicativo possui uma interface responsiva para celular, tablet e computador, além de suporte à instalação como PWA.

## Instalação

Abra `app.html` em um site servido por HTTPS (ou `localhost`) e use a opção **Instalar aplicativo** do navegador. O manifesto está em `manifest.json` e o cache offline em `sw.js`.
